# Epic 18: Calendar & Scheduling

## Overview
A dedicated Calendar tab providing day/week/month views of all jobs and appointments for the workspace. Users can view, create, and reschedule jobs directly from the calendar interface.

## Tasks
- [ ] **US-18.1**: "As a workspace user, I want a Calendar tab in the main sidebar navigation so I can view all scheduled jobs visually."
- [ ] **US-18.2**: "As a workspace user, I want to switch between day, week, and month views on the calendar."
- [ ] **US-18.3**: "As a workspace user, I want to click a date/time slot on the calendar to create a new job for that time."
- [ ] **US-18.4**: "As a workspace user, I want to drag and drop jobs on the calendar to reschedule them."
