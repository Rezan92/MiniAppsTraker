# Epic 10: User Hub, Settings & Notifications

## Overview
Activate the global header icons (Profile, Settings, Notifications) to provide the user with account management and alert functionality.

## Tasks
- [ ] **Task 10.1: User Profile UI**
  - Make the header profile avatar clickable, opening a dropdown or routing to `/profile`.
  - Display the logged-in user's email, name, role (e.g., Admin), and a "Log Out" button.
- [ ] **Task 10.2: Settings UI**
  - Make the settings/help gear icon clickable, routing to `/settings`.
  - Design a placeholder layout for future tenant-level settings (e.g., Company Name, Tax Rate, Billing preferences).
- [ ] **Task 10.3: Notification Center**
  - Make the notification bell icon clickable, triggering a slide-out drawer or popover menu.
  - Implement a basic UI state for "Empty Notifications" and placeholder styles for unread alerts (e.g., "New Job Assigned", "Estimate Approved").
