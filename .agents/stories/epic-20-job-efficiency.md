# Epic 20: Job Entry Efficiency (Bulk & Formatting)

## User Stories

- [ ] **US-20.1: Bulk Material Entry** — "As a user, I want a multi-row input form to add several job materials at once, rather than opening a modal one-by-one."
- [ ] **US-20.2: Bulk Hours Entry** — "As a user, I want a multi-row input form to log multiple labor hour entries at once."
- [ ] **US-20.3: Bullet-Point Descriptions for Labor** — "As a user, when I log hours on a job, I want the description field to support bulleted lists/rich text so that work items render as a clean list on the invoice."
