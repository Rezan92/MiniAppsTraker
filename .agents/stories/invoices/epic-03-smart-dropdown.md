# Epic 3: Smart Dropdown & A La Carte Selection

**Goal:** Build the Smart Dropdown UI that allows users to manually pick Labor Hours and Materials from the Job's ledger.

## User Stories

- [ ] **US-3.1: Backend — Fetch Job Items by Billing Status**
  - **As a** developer, **I want** API endpoints that return job items filtered by `billing_status` query param.
- [ ] **US-3.2: Smart Dropdown Component — Default View**
  - **As a** user, **I want** to see a dropdown of my Job's unbilled hours and materials when building an invoice.
- [ ] **US-3.3: "Show Already Billed" Toggle**
  - **As a** user, **I want** the option to see items that were already billed on previous invoices, to re-bill them.
- [ ] **US-3.4: "Include All" Button**
  - **As a** user, **I want** a quick action to add all currently visible items at once.
- [ ] **US-3.5: Ad-Hoc Line Items (Custom Charges)**
  - **As a** user, **I want** to add custom line items directly on the invoice without them being tied to a Job record.
