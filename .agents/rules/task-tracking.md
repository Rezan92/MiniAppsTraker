# Task State Management & Scope Tracking

1. **State Indicators:**
   - `[ ]` = To Do
   - `[/]` = In Progress (STRICT: Only ONE task in progress at a time)
   - `[x]` = Completed & Verified

2. **Workflow:**
   - Change task state to `[/]` before writing code.
   - Implement, verify, and update state to `[x]`.

3. **Dynamic Scope Additions:**
   - When new requirements, edge cases, or extra features are added during a ticket, add a `### Implementation Notes & Additions` block directly under the task in the markdown story file to maintain a complete history.
